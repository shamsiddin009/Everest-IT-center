# EVEREST ACADEMY — UX & RESPONSIVE RULES

## 1. Responsive Breakpoints
- **Mobile Compact (320px – 374px):** Single column, touch targets >= 44px, compact paddings (16px).
- **Mobile Standard (375px – 430px):** Standard fluid layout, stacked hero actions, sticky mobile navbar.
- **Tablet (768px – 1023px):** 2-column course and feature grids, responsive table and cards.
- **Laptop (1024px – 1439px):** 3-column grids, horizontal nav links, full interactive hero.
- **Large Desktop (1440px+):** Max-container width 1280px, optimized breathing room and high visual fidelity.

## 2. Touch & Navigation
- All tap targets are at least 44x44px.
- Zero horizontal overflow (`overflow-x: hidden`).
- Clean mobile drawer navigation with smooth slide-in transition.
- Explicit active navigation indicators for current page route.
